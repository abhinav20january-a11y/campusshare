# Vercel Commerce layout adaptation

Source: https://github.com/vercel/commerce/blob/main/components/grid/three-items.tsx
License: https://github.com/vercel/commerce/blob/main/license.md

The three-tile arrangement in client/src/components/common/CommerceGrid.jsx is adapted for React Router and local collection images. The application still uses the existing Express/MySQL backend; the Next.js/Shopify template backend was not imported. Other page layouts and styles are custom CampusShare implementation.
